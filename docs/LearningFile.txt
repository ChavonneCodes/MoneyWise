-How it will work:
Angular(Frontend) is what the user sees and interacts with. The frontend will send requests and receive responses from the Backend done in Express. The backend processes requests and handles application knowledge. The backend reads and saves information from the database. The database stores users,transactions,budgets, etc.

-WHAT IS MIDDLEWARE
-When someone sends a request to your backend, it passes through different functions before reaching its destination
-for example someone new arrives at a building you may have to show identification and pass through security etc
-1.Incoming request-Someone wants access to your backend
-2.Helmet-adds security headers
-3.CORS-Checks whether the requesting website is allowed
-4.express.json()-Reads JSON data sent with the request. Makes the data readable
-5.Route handler-Decides what to do with the request
-6.Response-Sends an answer back  to the frontend

WHAT HAPPENS WHEN SOMETHING  GOES WRONG
-AppError and errorHandler
-standard system for creating errors so that errors are created the same
-If something goes wrong because the user made a mistake we can explain the problem. If it is ecause of a programming bug we shouldnt expose technical details to the user for example dataase passwords or internal server  information
